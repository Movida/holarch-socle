# Les refus d'outil au journal

**Contexte.** Le besoin B2 cite les refus parmi ce qui reste invisible. Les transcriptions Claude Code les contiennent :
un résultat d'outil en erreur dont le texte commence par un message fixe, propre à chaque origine.

**Décision.**

| Point | Choix |
|---|---|
| Événement | `tool.denied`, dans la famille `tool.*` ; un par refus, horodaté, rattaché à la session (`correlation`) |
| Données | `outil`, `origine` (`humain`, `classifieur`, `regle`, `securite`, `hook`), `categorie` pour le classifieur (son libellé fixe, par exemple « Unauthorized Persistence »), `projet` |
| Jamais | la commande, le chemin ou le motif détaillé, qui peuvent porter des données |
| Repérage | seulement un résultat d'outil en erreur dont le texte **commence** par un message connu : un texte qui cite ces messages (une recherche dans les transcriptions, par exemple) n'est pas un refus |
| Affichage | refus sur 30 jours par origine et par outil (tableau de bord), refus par session, liste au journal |

**Conséquences.** Contrat événement 0.4.0 (famille `tool.*` : `called`, `denied`). Un message qui change dans une
version de Claude Code se rattrape en ajoutant son motif ; un refus non reconnu reste invisible, pas mal classé.
