# Types transverses

Ensembles de règles qu'un projet adopte en les citant dans `types` (décision `arbre-des-regles`, registre des types :
`template`). Un type dit un comportement ; le projet dit où sont ses registres.

- [`methode-holarch/index.md`](methode-holarch/index.md) - la méthode : brouillon jusqu'à approbation, fait inconnu marqué, rien à l'avance, décisions, revue, journal
- [`depot-public/index.md`](depot-public/index.md) - un dépôt public : rien de personnel dans un fichier suivi
