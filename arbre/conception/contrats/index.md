# Contrats

Les contrats sont le produit (principe P1). Chacun est versionné (semver) ; un changement incompatible est une décision.
Clés des données en anglais (outillage et partage), textes en français.

- [`noeud.md`](noeud.md) - un nœud de l'arbre : fichier, en-tête, liens, cycle de vie, héritage de configuration
- [`regle.md`](regle.md) - une règle : donnée, niveaux d'application, héritage, dérogation, règle effective
- [`fiche-catalogue.md`](fiche-catalogue.md) - une fiche du catalogue : tout élément en place
- [`evenement.md`](evenement.md) - un événement du journal : tout ce qui se passe
- [`acteurs.md`](acteurs.md) - la notation des acteurs (humains, agents, système)
