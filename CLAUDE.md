# HOLARCH — consignes pour une session d'agent dans ce dépôt

Les règles de ce dépôt viennent de son arbre (`arbre/rules.yaml`, types dans `arbre/types-transverses/`) ;
`holarch regles appliquer` les écrit dans `.claude/rules/holarch/`. Une règle se change à sa source, jamais dans un
fichier généré.

- Où vivent les choses : questions ouvertes dans `arbre/questions.md`, décisions en nœuds `decision` dans
  `arbre/decisions/`, contrats dans `arbre/conception/contrats/`.
- Journal (`arbre/log.md`) : `## AAAA-MM-JJ` puis `* **Sujet** : détail`, le plus récent en premier.
